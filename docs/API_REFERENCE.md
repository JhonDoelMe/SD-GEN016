# Документація REST API (/api/v1)

Усі маршрути API згруповані за доменними модулями та захищені за допомогою JWT Bearer токенів або HTTP-only Cookie.
Інтерактивна документація OpenAPI/Swagger доступна за адресою: `http://localhost:8000/docs` (або `http://localhost:8000/redoc`).

> [!NOTE]
> Усі тимчасові позначки передаються та повертаються в форматі ISO 8601 (UTC або Europe/Kyiv). Форматування для користувача у звітах та інтерфейсі відповідає ДСТУ 4163:2020.
> Багатосайтовість: запити підтримують необов'язкові або обов'язкові параметри `facility_id` та `generator_id` для фільтрації в межах конкретного об'єкта або генератора.

## 1. Автентифікація (`/api/v1/auth`)

### `POST /api/v1/auth/login`
- **Опис**: Вхід у систему, валідація пароля (bcrypt) та видача JWT Bearer токена.
- **Публічний доступ**: Так (з обмеженням Rate Limiting).
- **Тіло запиту**:
```json
{
  "login": "superadmin",
  "password": "SuperAdminPass123!"
}
```
- **Відповідь (200 OK)**:
```json
{
  "access_token": "eyJhbGciOi...",
  "token_type": "bearer",
  "user": {
    "id": 1,
    "login": "superadmin",
    "full_name": "Головний Системний Адміністратор",
    "is_superadmin": true,
    "roles": ["superadmin"],
    "permissions": ["generator:start", "system:adjust", "..."]
  }
}
```

### `GET /api/v1/auth/me`
- **Опис**: Інформація про поточного авторизованого користувача, призначені ролі та масив діючих дозволів (permissions).
- **Потрібен дозвіл**: Будь-який авторизований користувач.

### `POST /api/v1/auth/logout`
- **Опис**: Завершення сесії, інвалідація сесійних cookies та створення аудит-запису.
- **Потрібен дозвіл**: Будь-який авторизований користувач.

## 2. Локації та Об'єкти (`/api/v1/facilities`)

### `GET /api/v1/facilities`
- **Опис**: Отримання переліку всіх зареєстрованих об'єктів / локацій.
- **Потрібен дозвіл**: `facilities:view`

### `POST /api/v1/facilities`
- **Опис**: Створення нового виробничого майданчика або локації.
- **Потрібен дозвіл**: `facilities:manage`
- **Тіло запиту**:
```json
{
  "name": "Основна Резиденція (Київ)",
  "address": "вул. Хрещатик, 1",
  "is_active": true
}
```

### `GET /api/v1/facilities/{facility_id}`
- **Опис**: Отримання детальної інформації про конкретну локацію разом із прив'язаними генераторами та складами ГСМ.
- **Потрібен дозвіл**: `facilities:view`

### `PUT /api/v1/facilities/{facility_id}`
- **Опис**: Оновлення реквізитів або статусу локації.
- **Потрібен дозвіл**: `facilities:manage`

### `DELETE /api/v1/facilities/{facility_id}`
- **Опис**: Деактивація (м'яке видалення) або повне видалення локації (якщо відсутні прив'язані генератори).
- **Потрібен дозвіл**: `facilities:manage`

## 3. Генератори та Сесії Роботи (`/api/v1/generator`)

### `GET /api/v1/generator`
- **Опис**: Отримання стану активного генератора за замовчуванням або за `?generator_id=X`. Повертає статус, мотогодини, рівень палива в баку, графік регламентних робіт.
- **Потрібен дозвіл**: `generator:view`

### `GET /api/v1/generator/list`
- **Опис**: Отримання повного переліку генераторів парку (з фільтрацією `?facility_id=X`).
- **Потрібен дозвіл**: `generator:view`

### `POST /api/v1/generator`
- **Опис**: Додавання нового генератора в парк обладнання.
- **Потрібен дозвіл**: `generator:configure`
- **Тіло запиту**:
```json
{
  "facility_id": 1,
  "name": "SDMO Diesel 15kVA",
  "model": "SDMO J15",
  "serial_number": "SD-2026-994",
  "fuel_type": "ДП (дизель)",
  "tank_capacity_l": 65.0,
  "current_operating_hours": 12.5,
  "maintenance_interval_hours": 100.0,
  "nominal_consumption_l_per_h": 2.8
}
```

### `PUT /api/v1/generator/{generator_id}`
- **Опис**: Редагування паспортних параметрів та налаштувань генератора.
- **Потрібен дозвіл**: `generator:configure`

### `DELETE /api/v1/generator/{generator_id}`
- **Опис**: Видалення генератора або зняття з балансу.
- **Потрібен дозвіл**: `generator:configure`

### `POST /api/v1/generator/wizard`
- **Опис**: Початковий майстер налаштування або швидка переконфігурація первинних параметрів.
- **Потрібен дозвіл**: `generator:configure`

### `POST /api/v1/generator/start`
- **Опис**: Запуск генератора в режимі реального часу. Перевіряє графік роботи (Europe/Kyiv), відсутність блокуючих критичних несправностей та наявність палива.
- **Потрібен дозвіл**: `generator:start`
- **Тіло запиту**:
```json
{
  "generator_id": 1,
  "fuel_level_l": 25.0
}
```

### `POST /api/v1/generator/stop`
- **Опис**: Зупинка генератора. Розраховує тривалість сесії, списання палива за номіналом або фактичним залишком, прирощення мотогодин.
- **Потрібен дозвіл**: `generator:stop`
- **Тіло запиту**:
```json
{
  "generator_id": 1,
  "end_hours": 104.5,
  "end_fuel_level_l": 19.5,
  "note": "Відновлення міської електромережі"
}
```

### `POST /api/v1/generator/manual-run`
- **Опис**: Ретроспективне внесення сесії роботи генератора, якщо під час роботи був відсутній зв'язок або інтернет.
- **Потрібен дозвіл**: `generator:manual_run`
- **Тіло запиту**:
```json
{
  "generator_id": 1,
  "start_time": "2026-10-20T08:00:00Z",
  "end_time": "2026-10-20T11:00:00Z",
  "start_hours": 100.0,
  "end_hours": 103.0,
  "fuel_spent_l": 8.4,
  "reason": "Внесення за паперовим журналом чергового через аварію інтернет-провайдера"
}
```

### `GET /api/v1/generator/active-run`
- **Опис**: Перевірка наявності активної (запущеної) сесії роботи (з параметром `?generator_id=X`).
- **Потрібен дозвіл**: `generator:view`

### `GET /api/v1/generator/runs`
- **Опис**: Пагінований список історичних запусків та зупинок (query: `generator_id`, `limit=50`, `offset=0`).
- **Потрібен дозвіл**: `generator:view`

## 4. Паливний Баланс та Рух ГСМ (`/api/v1/fuel`)

### `GET /api/v1/fuel/summary`
- **Опис**: Зведений паливний баланс: поточний складський запас, пальне в баках генераторів, середня ціна літра (WOG або фактична), витрати в грн.
- **Потрібен дозвіл**: `fuel:view`

### `GET /api/v1/fuel/stocks`
- **Опис**: Перелік усіх складів пального (каністри, цистерни, резервуари) з розбивкою по локаціях.
- **Потрібен дозвіл**: `fuel:view`

### `POST /api/v1/fuel/stock/new` або `POST /api/v1/fuel/stocks`
- **Опис**: Створення нового паливного складу/резервуара.
- **Потрібен дозвіл**: `fuel:manage_stocks`
- **Тіло запиту**:
```json
{
  "facility_id": 1,
  "name": "Резервуар №1 (Дизель)",
  "capacity_liters": 1000.0,
  "fuel_type": "ДП"
}
```

### `PUT /api/v1/fuel/stocks/{stock_id}`
- **Опис**: Редагування назви чи місткості паливного складу.
- **Потрібен дозвіл**: `fuel:manage_stocks`

### `DELETE /api/v1/fuel/stocks/{stock_id}`
- **Опис**: Видалення паливного складу (лише за нульового залишку).
- **Потрібен дозвіл**: `fuel:manage_stocks`

### `POST /api/v1/fuel/receipt`
- **Опис**: Оприбуткування палива на склад ГСМ від постачальника (бензовоза).
- **Потрібен дозвіл**: `fuel:receipt`
- **Тіло запиту**:
```json
{
  "fuel_stock_id": 1,
  "liters": 200.0,
  "cost_total": 11600.0,
  "fuel_type": "ДП",
  "supplier": "WOG",
  "receipt_number": "ЧЕК-849201",
  "driver_name": "Коваленко О.В."
}
```

### `GET /api/v1/fuel/receipts`
- **Опис**: Історія надходжень палива.
- **Потрібен дозвіл**: `fuel:view`

### `POST /api/v1/fuel/transfer`
- **Опис**: Внутрішнє переміщення (заправка бака генератора зі складу ГСМ).
- **Потрібен дозвіл**: `fuel:transfer`
- **Тіло запиту**:
```json
{
  "source_stock_id": 1,
  "generator_id": 1,
  "liters": 25.0,
  "comment": "Заправка бака перед нічною зміною"
}
```

### `GET /api/v1/fuel/transfers`
- **Опис**: Журнал усіх внутрішніх переміщень/заправок.
- **Потрібен дозвіл**: `fuel:view`

## 5. Технічне Обслуговування (`/api/v1/maintenance`)

### `GET /api/v1/maintenance/schedule`
- **Опис**: Графік регламентних робіт (поточні мотогодини, мотогодини останнього ТО, поріг наступного ТО, залишок мотогодин, статус прострочення).
- **Потрібен дозвіл**: `maintenance:view`

### `POST /api/v1/maintenance/schedule/recalculate`
- **Опис**: Примусовий перерахунок залишкового ресурсу та дедлайнів ТО.
- **Потрібен дозвіл**: `maintenance:manage`

### `POST /api/v1/maintenance/record`
- **Опис**: Реєстрація факту виконання регламентного або проміжного ТО. Скидає лічильник міжсервісного інтервалу у разі `SCHEDULED`.
- **Потрібен дозвіл**: `maintenance:perform_scheduled` або `maintenance:create_intermediate`
- **Тіло запиту**:
```json
{
  "generator_id": 1,
  "maintenance_type": "SCHEDULED",
  "operating_hours_at_service": 100.2,
  "work_performed": "Заміна мастила 10W-40, заміна масляного та паливного фільтрів, перевірка клапанів",
  "consumables_used": "Мастило Mannol 2.5л, фільтр HF-124",
  "cost": 1850.0,
  "performed_by": "Сервіс ТОВ Дизель-Майстер"
}
```

### `GET /api/v1/maintenance/records`
- **Опис**: Історичний реєстр усіх проведених технічних обслуговувань.
- **Потрібен дозвіл**: `maintenance:view`

## 6. Журнал Несправностей та Дефектів (`/api/v1/faults`)

### `GET /api/v1/faults`
- **Опис**: Список несправностей генератора (фільтрація за статусом: `?status_filter=NEW`, `generator_id`).
- **Потрібен дозвіл**: `faults:view`

### `POST /api/v1/faults`
- **Опис**: Реєстрація дефекту або аварійної зупинки. Критична несправність (`CRITICAL`) блокує запуск генератора до її закриття.
- **Потрібен дозвіл**: `faults:create`
- **Тіло запиту**:
```json
{
  "generator_id": 1,
  "title": "Спрацювання аварійного термостата охолоджувача",
  "description": "Температура піднялась до 105C під навантаженням 12кВт",
  "priority": "CRITICAL"
}
```

### `PUT /api/v1/faults/{fault_id}/status`
- **Опис**: Життєвий цикл несправності (`NEW` -> `ACCEPTED` -> `IN_PROGRESS` -> `RESOLVED` -> `CLOSED`).
- **Потрібен дозвіл**: `faults:manage`
- **Тіло запиту**:
```json
{
  "status": "CLOSED",
  "resolution_comment": "Промито радіатор, замінено датчик температури, протестовано під навантаженням"
}
```

## 7. Web Push Сповіщення (`/api/v1/notifications`)

### `GET /api/v1/notifications/vapid-public-key`
- **Опис**: Отримання відкритого VAPID ключа сервера для підписки в браузері.
- **Публічний доступ**: Так.

### `POST /api/v1/notifications/subscribe`
- **Опис**: Реєстрація `PushSubscription` об'єкта клієнтського браузера / PWA.
- **Потрібен дозвіл**: Будь-який авторизований користувач.

### `POST /api/v1/notifications/unsubscribe`
- **Опис**: Відкликання активної push-підписки браузера.
- **Потрібен дозвіл**: Будь-який авторизований користувач.

### `GET /api/v1/notifications/settings`
- **Опис**: Отримання персональних налаштувань категорій сповіщень (запуск/зупинка, наближення ТО, критичні несправності, низький рівень палива).
- **Потрібен дозвіл**: Будь-який авторизований користувач.

### `PUT /api/v1/notifications/settings`
- **Опис**: Оновлення вподобань сповіщень.
- **Потрібен дозвіл**: Будь-який авторизований користувач.

### `POST /api/v1/notifications/test`
- **Опис**: Надсилання тестового Push-повідомлення на поточний пристрій.
- **Потрібен дозвіл**: `notifications:manage`

### `GET /api/v1/notifications/logs`
- **Опис**: Журнал успішних та неуспішних відправлень сповіщень.
- **Потрібен дозвіл**: `notifications:view`

### `POST /api/v1/notifications/check-maintenance/{generator_id}`
- **Опис**: Примусова перевірка порогів міжсервісного інтервалу та розсилка попереджень.
- **Потрібен дозвіл**: `notifications:manage`

## 8. Аналітика та Звіти (`/api/v1/reports`)

### `GET /api/v1/reports/summary`
- **Опис**: Отримання підсумкових метрик у JSON за вказаний часовий діапазон (`start_date`, `end_date`, `generator_id`, `facility_id`).
- **Потрібен дозвіл**: `reports:view`
- **Відповідь містить**:
  - `total_runs_count`: кількість запусків;
  - `total_operating_hours`: сумарні мотогодини (розраховані з точністю до секунд);
  - `total_fuel_consumed_l`: витрата палива;
  - `total_fuel_cost_uah`: грошова оцінка витраченого пального;
  - `average_hourly_consumption_l`: фактична питома витрата л/год;
  - `runs_summary`: деталізований перелік сесій;
  - `maintenance_summary`: перелік проведених ТО за період;
  - `fuel_movements`: прибуткування та внутрішні заправки.

### `GET /api/v1/reports/export-excel`
- **Опис**: Генерація та вивантаження офіційного бухгалтерського багатосторінкового Excel-звіту (`.xlsx`).
- **Потрібен дозвіл**: `reports:export`
- **Структура книги Excel (5 аркушів)**:
  1. `Зведений звіт` — паспорти генераторів, підсумкові витрати, грошова оцінка;
  2. `Журнал запусків` — часи пусків/зупинок, мотогодини, витрата;
  3. `Рух палива` — оприбуткування та переміщення ГСМ;
  4. `Журнал ТО` — регламентні роботи, витратні матеріали, вартість робіт;
  5. `Журнал дефектів` — несправності, статуси та заходи щодо їх усунення.

### `GET /api/v1/reports/export`
- **Статус**: Застарілий. Повертає `400 Bad Request` із рекомендацією використовувати `/api/v1/reports/export-excel`.

## 9. Системні Налаштування та Інтеграції (`/api/v1/system`)

### `GET /api/v1/system/status`
- **Опис**: Загальний стан здоров'я системи, перевірка з'єднання з базою даних, системний час Europe/Kyiv.
- **Публічний доступ**: Так (`/api/health` та `/api/v1/system/status`).

### `GET /api/v1/system/fuel-prices`
- **Опис**: Отримання поточних офіційних цін на пальне (парсинг сайту мережі АЗК WOG).
- **Потрібен дозвіл**: `fuel:view`

### `POST /api/v1/system/fuel-prices/refresh`
- **Опис**: Примусовий запуск парсера цін WOG у реальному часі.
- **Потрібен дозвіл**: `fuel:manage_stocks` або `system:adjust`

### `GET /api/v1/system/settings`
- **Опис**: Читання динамічних бізнес-параметрів системи з бази даних (порогові залишки бака, увімкнення розкладу пусків, ліміти).
- **Потрібен дозвіл**: `admin` або `superadmin`.

### `PUT /api/v1/system/settings`
- **Опис**: Оновлення системних налаштувань без перезапуску сервера.
- **Потрібен дозвіл**: `admin` або `superadmin`.

### `POST /api/v1/system/reset`
- **Опис**: Процедура повного очищення бази даних (Clean DB) та повторної ініціалізації.
- **Потрібен дозвіл**: **Виключно SuperAdmin** (`system:reset`).
- **Вимоги безпеки**: Потребує пароль супер-адміністратора та спеціальне підтвердження (`confirm_phrase: "RESET_ALL_DATA_PERMANENTLY"`).

## 10. Аудит Дій та Коригування (`/api/v1/audit`, `/api/v1/adjustments`)

### `GET /api/v1/audit`
- **Опис**: Незмінний журнал аудиту (Audit Trail). Фіксує ID користувача, IP-адресу, User-Agent, дію, сутність та попередні/нові значення полів.
- **Потрібен дозвіл**: `audit:view`

### `GET /api/v1/adjustments`
- **Опис**: Перегляд історії інвентаризаційних та системних коригувань.
- **Потрібен дозвіл**: `audit:view`

### `POST /api/v1/adjustments`
- **Опис**: Внесення офіційного коригування лічильника мотогодин або залишків палива за актом звірки.
- **Потрібен дозвіл**: **Виключно SuperAdmin** (`system:adjust`).
- **Тіло запиту**:
```json
{
  "entity_type": "Generator",
  "entity_id": 1,
  "field_name": "current_operating_hours",
  "new_value": "112.5",
  "reason": "Звірка з фізичним лічильником мотогодин згідно з Актом №14 від 20.10.2026"
}
```

## 11. Керування Користувачами та Ролями (`/api/v1/users`)

### `GET /api/v1/users`
- **Опис**: Перелік усіх зареєстрованих користувачів платформи.
- **Потрібен дозвіл**: `users:manage`

### `GET /api/v1/users/roles`
- **Опис**: Довідник доступних системних ролей (`superadmin`, `admin`, `operator`, `viewer`) та закріплених за ними прав.
- **Потрібен дозвіл**: `users:manage`

### `POST /api/v1/users`
- **Опис**: Створення нового облікового запису користувача.
- **Потрібен дозвіл**: `users:manage`

### `PUT /api/v1/users/{user_id}`
- **Опис**: Редагування ПІБ, статусу активності або зміна ролі користувача.
- **Потрібен дозвіл**: `users:manage`

### `POST /api/v1/users/{user_id}/reset-password`
- **Опис**: Скидання пароля облікового запису оператора/адміністратора.
- **Потрібен дозвіл**: `users:manage`

### `DELETE /api/v1/users/{user_id}`
- **Опис**: Деактивація користувача (деактивує прапорець `is_active`). Заборонено деактивувати єдиного супер-адміністратора.
- **Потрібен дозвіл**: `users:manage`
