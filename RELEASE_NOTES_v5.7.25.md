# Примітки до релізу SD-GEN016 v5.7.25 (Release Notes v5.7.16 — v5.7.25)

**Дата випуску:** 16 листопада 2026 року  
**Версія платформи та PWA:** `v5.7.25` (`sw.js`: `sd-gen016-v5.7.25`)  
**Версія Android APK:** `v5.7.25` (`versionCode 25`, підписаний APK + OTA)

Консолідований реліз **v5.7.16 — v5.7.25** переводить **SD-GEN016** на сучасну CMS-архітектуру без ручного `.env` та з майстром першого запуску (`/setup`), а також завершує комплексну офлайн-стійкість Web/PWA та Android APK і нативне завантаження файлів.

---

## 1. Архітектура без `.env` та Web Setup Wizard (`/setup`, `v5.7.22` — `v5.7.24`)
- **Адміністративний розділ `🖥️ Сервер та Інтеграції` (`SuperAdmin Only`, `v5.7.22`)**:
  - Усі секрети інтеграцій (`OpenWeatherMap`, `alerts.in.ua`, `UkraineAlarm`, JSON сервісного акаунту Firebase) шифруються симетрично (`Fernet enc:v1:`) у таблиці `system_settings`, маскуються як `"********"` при читанні та редактуються в аудиті й Excel.
  - Динамічне застосування `PRIMARY_DOMAIN`, `ALLOWED_HOSTS`, `CORS_ORIGINS`, JWT TTL та брутфорс-лімітів без перезапуску контейнера; живе тестування підключень (`POST /api/v1/system/server-config/test-integration`).
  - Кнопка **«Адреса сервера»** прихована на звичайних браузерах/PWA і доступна виключно всередині нативного Android APK.
- **Zero-`.env` Bootstrap (`data/instance.config.json`, `v5.7.23`)**:
  - Автономна генерація 64-символьного `app_secret_key` (`0o600`), перемикач рушіїв БД (`reinit_database_engine()`) і діагностика підключень (`probe_database_connection()`), постійний том Docker `data_storage:/app/data`.
- **Одноразовий Web Setup Wizard (`/setup`, `v5.7.24`)**:
  - При чистій інсталяції з архіву без `.env` система відкриває 4-кроковий майстер (організація/домен, вибір `SQLite` або `PostgreSQL`, створення `SuperAdmin`, опційні API-ключі) та незворотно блокує його (`403`) після завершення.
  - Для вже запущених систем додано кнопку міграції у Zero-`.env` формат (`POST /api/v1/system/server-config/migrate-zero-env`).

## 2. Повна офлайн-стійкість Web/PWA та Android `WorkManager` (`v5.7.20` — `v5.7.21`)
- **Stage 1 (`v5.7.20`)**:
  - При простроченні сесії (`401`) очищується лише кеш читання (`clearCacheOnly()`), а черга невідправлених подій зберігається до повторного входу.
  - `AbortController` таймаут `15 с` у запитах, backoff-повтори (`15 с → 30 с → 60 с`), автосинхронізація при поверненні у застосунок і чесний розрахунок мотогодин/палива за фактичним часом натискання (`event_timestamp`).
- **Stage 2 (`v5.7.21`)**:
  - Нативна SQLite-черга в Android APK (`OfflineQueueStore`), фонова доставка через Android `WorkManager` (`OfflineSyncWorker` + `OfflineSyncEngine`) і апаратне шифрування токена в `AndroidKeyStore` (`OfflineAuthVault`).

## 3. Нативне збереження файлів на Android та UX адмінки (`v5.7.16` — `v5.7.19`)
- **`FileDownloadPlugin` (`v5.7.18` — `v5.7.19`)**: звіти Excel, А4 PDF-відомості та `.zip` бекапи на Android зберігаються напряму в `Download/SD-GEN016/` через `MediaStore` (із SAF-резервом та тостами результату).
- **Модернізація адмін-панелі (`v5.7.16` — `v5.7.17`)**: доменна структура підвкладок, згортані картки-спойлери `<details class="admin-spoiler">` із бейджами статусу та незалежним збереженням секцій.
