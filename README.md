Виробнича (production-ready) система оперативного обліку фактичної експлуатації бензинового генератора на об'єкті.

Система спроектована для ручної фіксації подій оператором і забезпечує прозору, безперервну та перевірювану історію:
**Генератор → Експлуатація → Мотогодини → Паливо (Склад ГСМ ↔ Бак) → ТО (Регламентне / Проміжне) → Несправності → Звітність → Аудит**.

---

## ⚡ Ключові можливості

1. **Головна панель оператора (Dashboard)**:
   - Великі кнопки «ЗАПУСТИТИ» / «ЗУПИНИТИ», оптимізовані для роботи однією рукою біля генератора на смартфоні.
   - Живий моніторинг стану: *Остановлен, Работает, Требуется ТО, Неисправен, Заблокирован*.
   - Облік накопичувальних мотогодин та рівня палива в баку.
2. **Контроль робочого графіка та часу (Europe/Kyiv)**:
   - Дозволений період роботи (наприклад 08:00–20:00) перевіряється на сервері.
   - Зупинка генератора дозволена у будь-який час (безпековий пріоритет).
   - Врахування літнього/зимового часу в Україні через `ZoneInfo("Europe/Kyiv")`.
3. **Роздільний облік палива**:
   - Склад ГСМ ↔ Бак генератора.
   - Оприбуткування палива за чеком із розрахунком ціни за літр (грн/л) та фіксацією водія бензовоза.
   - Захист від від'ємних залишків та переповнення бака генератора.
4. **Технічне обслуговування (ТО)**:
   - **Регламентне ТО**: прив'язане до мотогодин (наприклад кожні 300 год) із подовженням інтервалу.
   - **Проміжне ТО**: заміна свічок, фільтрів, очищення — **не скидає** основний регламентний інтервал і лічильник годин!
5. **Журнал несправностей**:
   - Пріоритети (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`).
   - Критичні дефекти автоматично переводять генератор у стан `FAULTY` та блокують повторний запуск.
   - Повний життєвий цикл: *NEW → ACCEPTED → IN_PROGRESS → PENDING → RESOLVED → CLOSED*.
6. **Ролі та дозволи (RBAC)**:
   - `superadmin`, `admin`, `operator`, `viewer`.
   - Авторизація через JWT та безпечні HTTP-only Cookies.
   - Безпечне хешування паролів за стандартом Bcrypt.
7. **Незмінний аудит та системні коригування**:
   - Будь-яка дія записується в `audit_logs`.
   - Системні коригування лічильників дозволені **виключно SuperAdmin** з обов'язковою фіксацією причини зміни, старого та нового значень.
8. **Аналітична звітність та експорт**:
   - Розрахунок мотогодин, розходу, витрат на закупівлю палива та ТО за вибраний період.
   - Експорт звіту у формат CSV з UTF-8 BOM для Excel.
9. **Підтримка PWA (Android / iOS / Desktop)**:
   - Web App Manifest (`manifest.json`), іконки (192px, 512px).
   - Service Worker (`sw.js`) з кешуванням та підтримкою автономного запуску (`display: standalone`).

## 🚀 Швидкий запуск

### 1. Локальний запуск (Development)

Вимоги: Python 3.14+
```bash
# Клонування репозиторію
git clone https://github.com/JhonDoelMe/SD-GEN016.git
cd SD-GEN016

# Встановлення залежностей
pip install -r backend/requirements.txt

# Копіювання конфігурації
cp .env.example .env

# Застосування міграцій бази даних
alembic upgrade head

# Запуск серверу розробки
python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload
```

Відкрийте браузер:
- Веб-додаток: [http://localhost:8000](http://localhost:8000)
- Документація Swagger API: [http://localhost:8000/docs](http://localhost:8000/docs)

**Первинний вхід:**
- Логін: `superadmin`
- Пароль: `SuperAdminPass123!` (або заданий у вашому `.env`)

---

### 2. Запуск у Docker / VPS (Production)

```bash
# Створіть та налаштуйте .env
cp .env.example .env

# Запуск контейнерів
docker compose up -d --build
```

Система автоматично підніме:
- Додаток FastAPI (порт 8000)
- Базу даних PostgreSQL 16
- Nginx Reverse Proxy (порти 80, 443)
- Автоматично застосує міграції Alembic і створить початкового системного адміністратора.

## 🧪 Автоматизоване тестування

Проект покритий повним набором автоматизованих тестів (`pytest`):
```bash
python -m pytest backend/tests -v
```

Тести перевіряють усі критичні бізнес-правила:
- Створення та вхід первинного адміністратора;
- Авторизацію та права доступу ролей (RBAC);
- Майстер налаштування та повний життєвий цикл генератора;
- Серверні перевірки робочого графіка за часом Києва;
- Зупинку генератора у будь-який час та незменшуваність мотогодин;
- Оприбуткування палива та розрахунок ціни за літр;
- Переміщення палива в бак, захист від від'ємного залишку та переповнення;
- Регламентне ТО з подовженням інтервалу;
- Проміжне ТО та невплив на основний регламентний інтервал;
- Життєвий цикл дефектів та блокування пуску при критичних аваріях;
- Системні коригування тільки SuperAdmin з обов'язковою причиною;
- Неможливість звичайного користувача виконати системне коригування;
- Формування аналітичних звітів та експорт у CSV.

## 📦 Резервне копіювання та відновлення

Створення резервної копії (БД + файли вкладень + налаштування):
```bash
python scripts/backup.py
# або на Linux:
sh scripts/backup.sh
```

Відновлення з резервної копії:
```bash
python scripts/restore.py backups/backup_sd_gen016_YYYYMMDD_HHMMSS.tar.gz
# або на Linux:
sh scripts/restore.sh backups/backup_sd_gen016_YYYYMMDD_HHMMSS.tar.gz
```
