## 🎯 Огляд випуску

Версія **v5.0.0** — це визначний ювілейний реліз системи **SD-GEN016**, що виводить комплекс на якісно новий рівень оперативної безпеки та польової готовності в умовах енергетичної кризи та воєнного стану в Україні.

Головні інженерні напрямки релізу:
1. **Повітряна безпека та раннє сповіщення (`BR-ALERT-01`)**: каскадний моніторинг тривог (`alerts.in.ua` -> `ukrainealarm.com` -> `MockAlertProvider`), розпізнавання типів небезпеки (балістика, крилаті ракети, БПЛА «Шахеди», зліт МіГ-31К, скидання КАБ, артобстріл), аварійний стробоскопічний маяк (Beacon Strobe), вібрація сирени та інтерактивна модальна шторка цивільної безпеки для оператора.
2. **Метеорологічна телеметрія та поради (`BR-WEATHER-01`)**: інтеграція OpenWeatherMap API з кешуванням у пам'яті (15 хв), автоматичне геокодування населеного пункту з фізичної адреси об'єкта (Дніпро, Самар, Київ, Буча, Львів, Харків тощо), моніторинг температури, відчутної температури, вологості, вітру й тиску, а також автоматичні інженерні поради для зимової (< 0°C), оптимальної та спекотної (> +25°C) експлуатації генератора.
3. **Польове зміцнення та захист від дефектів**:
   - **BR-GEN-14**: 60-секундний таймер охолодження двигуна після зупинки (захист свічок, випускних клапанів та паливної системи від термічного удару);
   - **BR-FUEL-09**: уніфікований склад ГСМ («Власні запаси / Каністри / Склад ГСМ») без штучного обмеження мережами АЗС;
   - **BR-REPORT-05**: безперервний календарний експорт звітів Excel зі збереженням днів простою для 100% точності бухгалтерського обліку;
   - Структурований людинозрозумілий аудит українською мовою (`ua_action`, `ua_entity`) із фіксацією клієнтського IP.
4. **Мобільна довершеність (Mobile Perfection v5.0.0)**:
   - Дворядкова представницька шапка для смартфонів (рядок брендингу та профіль користувача + рядок швидких індикаторів);
   - Жорсткий захист від горизонтального зсуву (`max-width: 100vw; overflow-x: hidden`);
   - Повноекранні модальні Bottom Sheets на мобільних пристроях;
   - Повна відповідність вимогам контрастності WCAG AA у світлій та темній темах.
5. **Адаптація під ліміти запитів GitLab (Multi-Remote Push to `main`)**:
   - Консолідація пушів (Zero Micro-Pushes) для запобігання помилкам `HTTP 429 Too Many Requests`;
   - Синхронний пуш у три віддалені репозиторії: `origin` (GitHub), `gitlab`, `codeberg`.

## ⚡ Детальний опис нових можливостей

### 1. Підсистема повітряної безпеки об'єкта (`alert_service.py`, `BR-ALERT-01`)
- **Каскадна архітектура провайдерів**:
  - `alerts.in.ua`: первинний офіційний API-шлюз із Bearer-автентифікацією;
  - `api.ukrainealarm.com`: вторинний резервний API-шлюз із API-ключем;
  - `MockAlertProvider`: автономний детермінований шлюз для безпечної роботи у тестових та офлайн-середовищах.
  - Автоматичне перемикання при тайм-аутах чи мережевих збоях; TTL-кешування на 30 секунд.
- **Диференціація загроз та візуальні маяки**:
  - `green` (Відбій): штатний режим роботи, безпечно;
  - `yellow` (Підвищена готовність): загроза ударних БПЛА («Шахеди») чи тактичної авіації;
  - `red` (Повітряна тривога): ракетна небезпека, балістика, зліт МіГ-31К, КАБ, артобстріл.
- **Анімації та інтерфейс**:
  - `alertEmergencyBeacon` / `alertEmergencyBeaconLight`: яскравий пульсуючий червоний ореол на всю панель тривоги;
  - `alertSirenWiggle`: механічна вібрація іконки сирени;
  - `alertDotFlash`: стробоскопічне миготіння індикатора небезпеки.

### 2. Метеорологічна телеметрія об'єкта (`weather_service.py`, `BR-WEATHER-01`)
- **Автоматичне визначення міста**: регулярний вираз виділяє назву міста з адреси об'єкта (`м. Дніпро`, `м. Самар`, `м. Київ`, `м. Буча` тощо) та перетворює її на географічні координати.
- **Показники клімату**: фактична температура, відчутна температура, вологість (%), швидкість вітру (м/с), атмосферний тиск (гПа).
- **Інженерні рекомендації оператору**:
  - Мороз (< 0°C): використання зимового палива, прогрів двигуна 3–5 хв без навантаження, контроль заряду АКБ;
  - Оптимально (0°C .. +25°C): штатний режим експлуатації;
  - Спека (> +25°C): вільний приплив повітря, контроль перегріву альтернатора, частий огляд рівня оливи.

### 3. Польове зміцнення ядра (Field-tested Defect Hardening)
- **Запобіжник повторного пуску (BR-GEN-14)**:
  - Після зупинки генератора кнопка блокується на 60 секунд;
  - Серверне відхилення пуску з кодом `400 Bad Request` («Двигун охолоджується, зачекайте...»);
  - Захист випускних клапанів, свічок запалювання та карбюратора/ТНВД від термоудару.
- **Уніфікований облік запасів палива (BR-FUEL-09)**:
  - Знято прив'язку до обов'язкового вибору мережі АЗС WOG/OKKO;
  - Підтримка узагальненого складу «Склад ГСМ», «Власні запаси», «Каністри» з можливістю введення довільного стороннього постачальника.
- **Календарна безперервність звітів Excel (BR-REPORT-05)**:
  - Формування звіту по днях без пропусків дат; дні простою відображаються з нульовими мотогодинами та точними залишками палива.
- **Людинозрозумілий україномовний аудит**:
  - Структуровані описи операцій (`ua_action`, `ua_entity`) з відображенням літражу, типу палива, назви генератора та IP-адреси клієнта.

### 4. Мобільна довершеність (Mobile Perfection v5.0.0)
- Дворядкова шапка на смартфонах: логотип та профіль у першому рядку, погодний та тривожний віджети у другому рядку.
- Горизонтальна фіксація `max-width: 100vw; overflow-x: hidden`.
- Повноекранні модальні Bottom Sheets на смартфонах із заокругленими верхніми кутами.
- Контрастність темної та світлої тем за стандартом WCAG AA.
