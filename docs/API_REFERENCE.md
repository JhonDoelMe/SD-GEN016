# Документація REST API (/api/v1)

**Версія API:** 5.4.0 (Dual-Provider Alert Fusion, WebPush Live Alerts, 5-Day Forecast, YASNO Fuel Readiness)  
**Дата набрання чинності:** 11 листопада 2026 року  

Усі маршрути API згруповані за доменними модулями та захищені за допомогою JWT Bearer токенів або HTTP-only Cookie.
Інтерактивна документація OpenAPI/Swagger доступна за адресою: `http://localhost:8000/docs` (або `http://localhost:8000/redoc`).

> [!NOTE]
> - **Час та стандарти**: Усі тимчасові позначки передаються та повертаються в форматі ISO 8601 (UTC або Europe/Kyiv). Форматування для користувача у звітах та інтерфейсі відповідає **ДСТУ 4163:2020**.
> - **Жорстка Multi-site ізоляція (Варіант Б)**: оператори та спостерігачі мають доступ **виключно** до свого закріпленого об'єкта (`user.facility_id`). Спроби доступу до ресурсів інших об'єктів повертають `403 Forbidden`. Адміністратори (`admin`) та `superadmin` мають глобальний доступ до всіх локацій.
> - **Валідація `generator_id`**: якщо передано явний `generator_id`, якого немає в базі даних, повертається `404 Not Found`. Якщо параметр відсутній (`None`) — обирається генератор за замовчуванням для дозволеного об'єкта.

## 1. Автентифікація (`/api/v1/auth`)

### `POST /api/v1/auth/login`
- **Опис**: Вхід у систему, валідація пароля (bcrypt) та видача JWT Bearer токена.
- **Публічний доступ**: Так (з подвійним обмеженням Rate Limiting: за парою `ip:{ip}:{login}` та глобально за обліковим записом `acct:{login}`, що унеможливлює підбір через ротацію IP).
- **Тіло запиту**:
```json
{
  "login": "operator1",
  "password": "OperatorPass123!",
  "remember_me": true
}
```
- **Відповідь (200 OK)**:
```json
{
  "access_token": "eyJhbGciOi...",
  "token_type": "bearer",
  "user": {
    "id": 2,
    "login": "operator1",
    "full_name": "Іван Оператор",
    "facility_id": 1,
    "is_superadmin": false,
    "roles": ["operator"],
    "permissions": ["generator:start", "generator:stop", "fuel:receipt", "..."]
  }
}
```
- **Безпекова примітка**: У корисне навантаження JWT додається клейм `pwd_sig` (HMAC-SHA256 підпис хешу пароля). Будь-яка зміна або скидання пароля робить старі токени недійсними на всіх пристроях.

### `GET /api/v1/auth/me`
- **Опис**: Інформація про поточного авторизованого користувача, його закріплений об'єкт (`facility_id`), призначені ролі та масив діючих дозволів (`permissions`).
- **Потрібен дозвіл**: Будь-який авторизований користувач (перевіряється актуальність `pwd_sig` та відсутність токена в списку відкликаних).

### `POST /api/v1/auth/change-password`
- **Опис**: Безпечна самостійна зміна пароля поточним авторизованим користувачем.
- **Потрібен дозвіл**: Будь-який авторизований користувач.
- **Тіло запиту**:
```json
{
  "current_password": "OperatorPass123!",
  "new_password": "NewOperatorPass456!"
}
```
- **Поведінка**:
  - `200 OK`: Пароль успішно змінено.
  - `400 Bad Request`: Невірний поточний пароль або спроба встановити ідентичний пароль.
  - `422 Unprocessable Entity`: Новий пароль не відповідає політиці складності (мін. 8 символів, наявність літер та цифр).
  - **Інвалідація сесій**: Одразу після зміни пароля всі попередні токени сесій на всіх пристроях користувача перестають діяти (`401 Unauthorized`). Для продовження роботи необхідно виконати вхід із новим паролем.

### `POST /api/v1/auth/forgot-password`
- **Опис**: Запит на відновлення пароля через email. Захищено від витоку існування користувачів (завжди повертає нейтральну відповідь), атак перебором та timing-атак.
- **Публічний доступ**: Так (діє ліміт Rate Limiting: не більше 3 спроб за 15 хвилин).
- **Тіло запиту**:
```json
{
  "login_or_email": "operator1@company.com"
}
```
- **Відповідь (200 OK)**:
```json
{
  "status": "ok",
  "message": "Якщо вказаний логін або email зареєстровано в системі та має прив'язану адресу електронної пошти, інструкції для відновлення надіслано на вашу пошту."
}
```
- **Безпека**: Генерується криптографічний 32-байтовий одноразовий токен (`secrets.token_urlsafe(32)`). У базі зберігається виключно його SHA-256 хеш. Термін дії токена — **20 хвилин**.

### `POST /api/v1/auth/reset-password`
- **Опис**: Встановлення нового пароля за дійсним одноразовим токеном відновлення.
- **Публічний доступ**: Так.
- **Тіло запиту**:
```json
{
  "token": "dGhpcy1pcy1hLXNhbXBsZS1zZWN1cmUtdG9rZW4...",
  "new_password": "NewSecurePassword2026!"
}
```
- **Відповідь (200 OK)**:
```json
{
  "message": "Пароль успішно змінено. Тепер ви можете увійти з новим паролем."
}
```
- **Безпека**:
  - Токен маркується як використаний (`used = True`) і не може бути застосований повторно;
  - Оновлення пароля змінює `pwd_sig`, що миттєво робить недійсними всі раніше видані JWT токени на всіх пристроях користувача;
  - Якщо в налаштуваннях увімкнено сповіщення, користувач отримує лист-підтвердження про зміну пароля з фіксацією часу та IP.

### `POST /api/v1/auth/logout`
- **Опис**: Завершення сесії. Додає поточний токен до списку відкликання `_REVOKED_TOKENS`, очищує сесійні Cookies та фіксує подію в аудиті.
- **Потрібен дозвіл**: Будь-який авторизований користувач.

## 2. Локації та Об'єкти (`/api/v1/facilities`)

### `GET /api/v1/facilities`
- **Опис**: Отримання переліку об'єктів. Для `operator`/`viewer` автоматично фільтрується виключно до їхнього `user.facility_id`. Для `admin`/`superadmin` повертає повний список.
- **Потрібен дозвіл**: Будь-який авторизований користувач (`get_current_user` + `verify_facility_access`).

### `POST /api/v1/facilities`
- **Опис**: Створення нового виробничого майданчика або локації.
- **Потрібен дозвіл**: `facility:configure` (ролі `admin`, `superadmin`).
- **Тіло запиту**:
```json
{
  "name": "Основна Резиденція (Київ)",
  "address": "вул. Хрещатик, 1",
  "description": "Головна виробнича база",
  "timezone": "Europe/Kyiv",
  "default_fuel_provider": "wog",
  "is_active": true
}
```
- **Параметр `default_fuel_provider`**: основна мережа АЗС за замовчуванням для об'єкта (`"wog"` або `"okko"`, за замовчуванням `"wog"`).

### `GET /api/v1/facilities/{facility_id}`
- **Опис**: Детальна інформація про локацію разом із генераторами та складами ГСМ.
- **Потрібен дозвіл**: Будь-який авторизований користувач. Для `operator`/`viewer` дозволено лише якщо `facility_id == user.facility_id` (інакше `403 Forbidden`).

### `PUT /api/v1/facilities/{facility_id}`
- **Опис**: Оновлення реквізитів або статусу локації, включаючи основну мережу АЗС (`default_fuel_provider`: `"wog"` або `"okko"`), місто (`city`) та налаштування моніторингу графіків відключень YASNO (`yasno_enabled`, `yasno_region_id`, `yasno_dso_id`, `yasno_group`).
- **Потрібен дозвіл**: `facility:configure`.

### `GET /api/v1/facilities/{facility_id}/outage-schedule`
- **Опис**: Отримання актуального прогнозу та погодинного графіка планових/ймовірних відключень електроенергії (YASNO / ДТЕК / ЦЕК) для обраного об'єкта за його чергою/підгрупою (наприклад, група `3.2` у м. Самар). Кешується на 15 хвилин; містить поля `is_outage_now`, `current_outage`, `yasno_updated_on` та `checked_at` (для розрахунку блоку готовності палива на клієнті).
- **Потрібен дозвіл**: Будь-який авторизований користувач (для `operator`/`viewer` — лише свій закріплений об'єкт).
- **Відповідь (200 OK)**:
```json
{
  "facility_id": 1,
  "facility_name": "Основний об'єкт (м. Самар)",
  "enabled": true,
  "region_id": 3,
  "dso_id": 301,
  "group": "3.2",
  "today": {
    "date": "2026-10-26",
    "status": "SCHEDULE_APPLIED",
    "slots": [
      {
        "start": "06:00",
        "end": "10:00",
        "type": "DEFINITE"
      },
      {
        "start": "14:00",
        "end": "18:00",
        "type": "PROBABLE"
      }
    ],
    "timeline": [
      { "hour": 0, "type": "DEFINITE", "is_current": false },
      { "hour": 10, "type": "NOT_PLANNED", "is_current": true }
    ]
  },
  "tomorrow": {
    "date": "2026-10-27",
    "status": "NO_OUTAGES",
    "slots": [],
    "timeline": []
  },
  "next_outage": {
    "type": "DEFINITE",
    "start": "14:00",
    "minutes_left": 185,
    "time_left_formatted": "3 год 5 хв"
  },
  "last_updated_at": "2026-10-26T10:15:00"
}
```

### `DELETE /api/v1/facilities/{facility_id}`
- **Опис**: Видалення або каскадне очищення об'єкта.
- **Query-параметр `cascade`** (опціонально, `bool`, за замовчуванням `false`):
  - Якщо `cascade=false`: видалення дозволено лише за умови відсутності активних генераторів та складів (інакше `400 Bad Request`).
  - Якщо `cascade=true`: повне каскадне видалення об'єкта разом із пов'язаними генераторами, складами ГСМ, сеансами напрацювання, записами ТО, дефектами та записами інвентаризаційних коригувань (`system_adjustments`) без порушення foreign key constraints.
- **Потрібен дозвіл**: **Виключно SuperAdmin** (`get_current_superadmin`), дія записується в незмінний журнал системного аудиту (`FACILITY_DELETE`).

---

### `GET /api/v1/facilities/{facility_id}/weather`
- **Опис**: Отримання актуальних метеорологічних умов, **5-денного прогнозу OpenWeatherMap (`forecast`)** та інженерних рекомендацій для генератора на обраному об'єкті (`updated_at` у `Europe/Kyiv`).
- **Кешування**: 20 хвилин (`WEATHER_CACHE_MINUTES`) у пам'яті бекенду. Підтримує `?force=true`.
- **Потрібен дозвіл**: Авторизований користувач із доступом до об'єкта.

### `GET /api/v1/facilities/{facility_id}/alert`
- **Опис**: Отримання поточного статусу повітряної безпеки об'єкта (`green` / `yellow` / `red`), типу загрози (`drones`, `ballistic`, `cruise`, `mig31k`, `bombs`, `artillery`), результату взаємної звірки провайдерів (`verification_status`: `verified` / `insurance_hold` / `single_source` / `mock`, `verification_note`) та інструкції цивільного захисту.
- **Кешування**: 15 с (`ALERTS_CACHE_SECONDS`) / 60 с (`UKRAINE_ALARM_CACHE_SECONDS`) при паралельній звірці `alerts.in.ua` + `api.ukrainealarm.com` (або `MockAlertProvider`). Підтримує `?force=true`.
- **Потрібен дозвіл**: Авторизований користувач із доступом до об'єкта.

### `GET /api/v1/facilities/{facility_id}/status-indicators`
- **Опис**: Об'єднаний легкий ендпоінт швидкого паралельного отримання погоди (`weather` з 5-денним прогнозом) та тривог (`alert` з двоканальною звіркою) в одному запиті для шапки PWA.
- **Потрібен дозвіл**: Авторизований користувач із доступом до об'єкта.

### `POST /api/v1/facilities/demo-alert`
- **Опис**: Тестова зміна статусу тривоги для навчання чергового персоналу та перевірки стробоскопічної анімації і push-сповіщень.
- **Потрібен дозвіл**: **Виключно SuperAdmin** (`get_current_superadmin`).

## 3. Генератори та Сесії Роботи (`/api/v1/generator`)

### `GET /api/v1/generator`
- **Опис**: Отримання стану генератора за `?generator_id=X` або дефолтного для дозволеного об'єкта.
- **Потрібен дозвіл**: `generator:view` (перевіряється належність генератора до об'єкта користувача).
- **Помилки**: `404 Not Found` (якщо явний `generator_id` не існує), `403 Forbidden` (якщо генератор належить іншому об'єкту).

### `GET /api/v1/generator/list`
- **Опис**: Отримання списку генераторів (з можливістю фільтрації `?facility_id=X`).
- **Потрібен дозвіл**: `generator:view`.

### `POST /api/v1/generator`
- **Опис**: Додавання нового генератора в парк обладнання.
- **Потрібен дозвіл**: `generator:configure`.
- **Тіло запиту**:
```json
{
  "facility_id": 1,
  "name": "Honda EU30i",
  "model": "EU30i",
  "manufacturer": "Honda",
  "serial_number": "SN-HONDA-2026-001",
  "rated_power_kw": 3.0,
  "tank_capacity_l": 13.0,
  "fuel_type": "А-95",
  "nominal_consumption_l_per_h": 1.5,
  "initial_operating_hours": 0.0,
  "maintenance_interval_hours": 100.0,
  "timezone": "Europe/Kyiv"
}
```

### `PUT /api/v1/generator/{generator_id}`
- **Опис**: Редагування паспортних параметрів та налаштувань генератора.
- **Потрібен дозвіл**: `generator:configure`.

### `DELETE /api/v1/generator/{generator_id}`
- **Опис**: Видалення генератора або м'яке архівування (`ARCHIVED`) за наявності історичних записів.
- **Потрібен дозвіл**: `generator:configure`.

### `POST /api/v1/generator/{generator_id}/restore`, `POST .../transfer-facility`, `POST .../reconcile`
- **Опис**: Відновлення архівованого генератора (`restore`), контрольоване перенесення генератора на інший об'єкт (`transfer-facility`) та діагностика/відновлення узгодженого статусу (`reconcile`).
- **Потрібен дозвіл**: `generator:configure`.

### `POST /api/v1/generator/start`
- **Опис**: Запуск генератора в режимі реального часу. Перевіряє права доступу до об'єкта, графік роботи, 60-секундний таймер охолодження (`BR-GEN-14`), відсутність критичних несправностей та наявність палива. Підтримує прапорець `force_start_with_maintenance: bool` для запуску генератора з простроченим регламентом ТО під відповідальність оператора.
- **Потрібен дозвіл**: `generator:start`.

### `POST /api/v1/generator/stop`
- **Опис**: Зупинка генератора (дозволена у будь-який час доби). Розраховує тривалість сесії, списання палива, приріст мотогодин.
- **Запобіжник опечатки (Typo Guard)**: Якщо приріст напрацювання перевищує 14 год або суттєво відхиляється від таймера (> 2.0 год), сервер повертає `400 Bad Request` із вимогою підтвердження (`force_confirm: true`).
- **Потрібен дозвіл**: `generator:stop`.

### `POST /api/v1/generator/manual-run`, `GET /api/v1/generator/active-run`, `GET /api/v1/generator/runs`
- **Опис**: Ретроспективне внесення сесії (`manual-run`, підтримує `force_confirm: bool`), отримання поточного активного запуску (`active-run`) та перегляд журналу запусків (`runs`).
- **Потрібен дозвіл**: `generator:start` (для `manual-run`), авторизований користувач (для читання в межах об'єкта).

## 4. Паливний Баланс та Рух ГСМ (`/api/v1/fuel`)

### `GET /api/v1/fuel/summary`
- **Опис**: Зведений паливний баланс у межах дозволеного об'єкта (запаси складів, пальне в баках, розрахунок витрат).
- **Потрібен дозвіл**: `fuel:view`.

### `GET /api/v1/fuel/stock`
- **Опис**: Перелік складів пального (з урахуванням ізоляції об'єктів `facility_id`).
- **Потрібен дозвіл**: `fuel:view`.

### `POST /api/v1/fuel/stock`
- **Опис**: Створення нового паливного складу/резервуара на об'єкті.
- **Потрібен дозвіл**: `fuel:configure`.

### `POST /api/v1/fuel/receipt`
- **Опис**: Оприбуткування палива на склад ГСМ за чеком або накладною із фіксацією постачальника/мережі АЗС.
- **Запобіжник партії та ціни (Scale & Price Sanity Check)**: Об'єм понад 1000 л або розрахункова ціна поза межами 15–250 грн/л блокуються з кодом `400 Bad Request`, якщо не встановлено `force_confirm: true`.
- **Потрібен дозвіл**: `fuel:receipt` (тільки для складів власного об'єкта).
- **Тіло запиту**:
```json
{
  "stock_id": 1,
  "liters": 100.0,
  "cost_total": 9290.0,
  "supplier": "АЗК WOG №12",
  "invoice_number": "ЧЕК-7812",
  "driver_name": "Іваненко І.І.",
  "fuel_provider": "wog",
  "comment": "Планове оприбуткування",
  "force_confirm": false
}
```
- **Параметр `fuel_provider`**: `"wog"` або `"okko"` (якщо не вказано, автоматично успадковується `default_fuel_provider` закріпленого об'єкта). Якщо `cost_total` не передано (або 0), вартість розраховується автоматично за актуальною ціною обраної мережі АЗС.

### `POST /api/v1/fuel/transfer`
- **Опис**: Внутрішнє переміщення (заправка бака генератора зі складу ГСМ того ж об'єкта).
- **Потрібен дозвіл**: `fuel:transfer`.

## 5. Технічне Обслуговування (`/api/v1/maintenance`)

### `GET /api/v1/maintenance/schedule` та `GET /api/v1/maintenance/schedules`
- **Опис**: Графік регламентних робіт для одного генератора (`schedule`, `404` при неіснуючому `generator_id`) або перелік графіків активних генераторів з фільтром `?facility_id=X` (`schedules`).
- **Потрібен дозвіл**: `maintenance:view`.

### `POST /api/v1/maintenance/schedule/recalculate`
- **Опис**: Примусовий перерахунок залишкового ресурсу та дедлайнів ТО.
- **Потрібен дозвіл**: `maintenance:perform_scheduled`.

### `POST /api/v1/maintenance/record`
- **Опис**: Фіксація факту проведення регламентного (`SCHEDULED`) або проміжного (`INTERMEDIATE`) ТО, а також скидання лічильника ТО після обслуговування сервісною службою.
- **Потрібен дозвіл**: `maintenance:perform_scheduled` або `maintenance:create_intermediate`.
- **Тіло запиту**:
```json
{
  "generator_id": 1,
  "maintenance_type": "SCHEDULED",
  "operating_hours": 600.0,
  "work_description": "Планове регламентне ТО (сервісна служба)",
  "consumables_used": "Моторна олива 10W-40 1.1л, фільтри",
  "cost": 1500.0,
  "comment": "Виїзне ТО, акт №12"
}
```
- **Параметр `operating_hours`** (`Optional[float]`): дозволяє адміністратору вказати точні мотогодини проведення робіт (актуально, коли сервісна служба провела ТО та повідомила про це пізніше). Оновлює `last_performed_hours` на вказане значення та зміщує планку `next_due_hours` на `+interval_hours` вперед (+300 год).

## 9. Резервне Копіювання (`/api/v1/backups`)

> [!IMPORTANT]
> Усі операції модуля резервного копіювання доступні **виключно SuperAdmin** (`is_superadmin = True`).

### `GET /api/v1/backups`
- **Опис**: Список наявних резервних копій, їхній розмір, SHA-256 хеші та кількість записів у таблицях.

### `POST /api/v1/backups`
- **Опис**: Створення повної (`full`) або часткової (`partial`/`db_only`) резервної копії.
- **Безпека**: Автоматично маскує значення паролів, ключів шифрування та рядків підключення до БД у конфігураційних файлах (`***REDACTED***`).

### `GET /api/v1/backups/{filename}/download`
- **Опис**: Завантаження ZIP-архіву резервної копії.
- **Безпека**: Захист від Path Traversal у назві файлу.

### `GET /api/v1/backups/{filename}/inspect`
- **Опис**: Перевірка цілісності архіву та читання `manifest.json` перед відновленням.

### `POST /api/v1/backups/{filename}/restore`
- **Опис**: Відновлення системи з наявного архіву на сервері. Потребує підтвердження `confirmation: "ВІДНОВИТИ"`.
- **Безпека**: Автоматично створює запобіжний зліпок перед початком очищення таблиць.

### `POST /api/v1/backups/upload-restore`
- **Опис**: Завантаження зовнішнього ZIP-архіву з комп'ютера адміністратора та відновлення системи.
- **Обмеження та захист**:
  - **Ліміт розміру**: Максимум **100 МБ** (`413 Payload Too Large`), обробляється потоковим читанням блоками по 64 КБ;
  - **Захист від Zip Slip**: перевірка шляхів файлів усередині архіву (заборона `..` та виходу за межі цільової папки);
  - **Захист від Zip Bomb**: ліміт розпакованого обсягу до 500 МБ або 10 000 файлів.

### `GET /api/v1/backups/settings` та `PUT /api/v1/backups/settings`
- **Опис**: Перегляд та оновлення розкладу автоматичного резервного копіювання (`backup_auto_enabled`, `backup_schedule_time`, `backup_frequency`, `backup_retention_count`, `backup_default_type`).

### `DELETE /api/v1/backups/{filename}`
- **Опис**: Видалення архіву резервної копії з диска сервера.


### `GET /api/v1/system/settings` та `PUT /api/v1/system/settings`
- **Опис**: Отримання та оновлення динамічних системних параметрів організації: робочий регламент, часовий пояс, тарифи, пороги контролю палива, параметри WOG, параметри поштового шлюзу (SMTP Primary/Fallback/Weekly) та **стартовий зв'язаний ланцюжок за замовчуванням** (`default_facility_id`, `default_generator_id`, `default_fuel_stock_id`).
- **Потрібен дозвіл**: `settings:manage` (`admin`, `superadmin`).
- **Безпека**: Паролі SMTP шлюзів маскуються (`********`) у відповідях API.

### `POST /api/v1/system/email/weekly-digest/send`
- **Опис**: Ручний запуск формування та відправки щотижневого звіту (файл Excel з 5 листами) на вказану адресу або отримувачам із системних налаштувань.

- **Query-параметр `recipient`** (опціонально): email або список через кому. Якщо не вказано — береться з параметра `email_weekly_recipients`.
- **Query-параметр `facility_id`** (опціонально): ідентифікатор цільового об'єкта для генерації книги Excel. Якщо не вказано — автоматично обирається `default_facility_id` або перший активний об'єкт.

### `POST /api/v1/system/reset`
- **Опис**: Безпечне очищення бази даних або скидання до заводського стану.
- **Потрібен дозвіл**: **Виключно SuperAdmin** з підтвердженням пароля адміністратора та кодовим словом `ОЧИСТИТИ` або `RESET`.

## 12. Моніторинг працездатності та інфраструктури (/api/health)

### `GET /api/health/liveness`
- **Опис**: Легковагова перевірка працездатності процесу веб-сервера (Liveness probe). Не виконує запитів до бази даних, відповідає миттєво.
- **Потрібен дозвіл**: Публічний (без авторизації).

```json
{
  "status": "alive"
```

- **Потрібен дозвіл**: Публічний (без авторизації).
- **Відповідь (200 OK — система здорова)**:
```json
{
  "status": "healthy",
  "facility_timezone": "Europe/Kyiv",
  "primary_domain": "https://sdgen.pp.ua",
  "database": "connected"
}
```
- **Відповідь (503 Service Unavailable — помилка з'єднання з БД)**:
```json
{
  "status": "unhealthy",
  "facility_timezone": "Europe/Kyiv",
  "primary_domain": "https://sdgen.pp.ua",
  "database": "disconnected"
}
```

## 14. Режим вимірювання витрат палива та інвентаризація (`/api/v1/measurement`, v5.6.0)

- **`GET /api/v1/measurement/status?facility_id={id}`**: Поточний статус вимірювання/блокування об'єкта, проміжний лічильник літрів (`measured_liters_total`), дозаправки, розрахункові `л/год` (доступно користувачам об'єкта).
- **`GET /api/v1/measurement/history?facility_id={id}`** *(SuperAdmin Only)*: Історія завершених, погоджених та скасованих контрольних замірів.
- **`POST /api/v1/measurement/start`** *(SuperAdmin Only)*: Запуск режиму вимірювання за умови зупиненого генератора і повного баку.
- **`POST /api/v1/measurement/{id}/finish-empty`** *(SuperAdmin Only)*: Підтвердження порожнього баку (мінімум 100 л відпрацьовано, генератор зупинено); блокує операції на об'єкті (`HTTP 423`) до завершення інвентаризації.
- **`POST /api/v1/measurement/{id}/inventory`** *(SuperAdmin Only)*: Фіксація фактичних залишків (бак, пули каністр, резерв, склади ГСМ) та складу комісії (мінімум 3 члени), присвоєння номера відомості `ІНВ-YYYYMMDD-NNN`.
- **`GET /api/v1/measurement/{id}/statement-pdf`** *(SuperAdmin Only)*: Генерація та завантаження офіційної відомості інвентаризації у форматі **PDF (А4, альбомна орієнтація)** із фіксацією факту скачування.
- **`POST /api/v1/measurement/{id}/approve`** *(SuperAdmin Only)*: Остаточне погодження після завантаження PDF — оновлення `nominal_consumption_l_per_h` та залишків, запис до аудиту й звітів, зняття блокування об'єкта.
- **`POST /api/v1/measurement/{id}/cancel`** *(SuperAdmin Only)*: Аварійне скасування вимірювання із обов'язковою причиною без зміни норми витрати та залишків.
